1. PDF COMPRESSION HELPER  (shipped in PdfHelper\)
-------------------------------------------------------------------------------

  PyMuPDF 1.25.3                          https://github.com/pymupdf/PyMuPDF
  MuPDF (bundled inside PyMuPDF)          https://mupdf.com
  Artifex Software, Inc.

  Licence: GNU Affero General Public License v3.0 (AGPL-3.0), or a commercial
  licence from Artifex Software.

  This is the most restrictive component in the package. StealthPDF ships PyMuPDF
  and MuPDF as compiled binaries under PdfHelper\, invoked as a separate process
  by Services/PdfCompressHelper.cs. Distributing those binaries carries an
  obligation to provide their corresponding source.

  That source ACCOMPANIES EVERY RELEASE as:

      StealthPDF-<version>-thirdparty-src.zip

  It holds the PyMuPDF source distribution for the exact version shipped, with
  MuPDF source inside it. PdfHelper\fetch-pdfhelper.ps1 downloads it from PyPI and
  verifies the published SHA-256 before it is packaged, so the source and the
  binaries can never be from different versions.

  It is a separate archive because StealthPDF's own source archive is built from
  git-tracked files only and PdfHelper\bundle\ is deliberately untracked (~55 MB of
  binaries), so it could not carry it.

  Run PdfHelper\fetch-pdfhelper.ps1 -Force to rebuild the exact bundle we ship.

  CPython (portable runtime shipped in PdfHelper\python\)
  https://www.python.org  -  Python Software Foundation License 2.0
